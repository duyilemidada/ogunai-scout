## Detailed Findings

### 1. 🟠 [HIGH] Missing HTTP Strict Transport Security (HSTS) Header

**Severity:** HIGH — Significant risk — fix within 1 week
**Attack Family:** `Transport Security`
**Endpoint/Target:** `https://fraudshield-xjgh.onrender.com`

**What was found:**
The server does not include the `strict-transport-security` header. Without HSTS, browsers are not forced to use HTTPS for subsequent requests, allowing SSL stripping attacks and exposing sensitive data in transit.

**Evidence:**
```json
"Header status: MISSING (severity: HIGH) \u2013 no HSTS header present in response from https://fraudshield-xjgh.onrender.com"
```

**How to fix it:** Add `Strict-Transport-Security: max-age=31536000; includeSubDomains` to all HTTPS responses.

### 2. 🟡 [MEDIUM] Missing Content Security Policy (CSP) Header

**Severity:** MEDIUM — Moderate risk — address in next sprint
**Attack Family:** `Content Security`
**Endpoint/Target:** `https://fraudshield-xjgh.onrender.com`

**What was found:**
The `content-security-policy` header is absent, providing no browser‑level restrictions on which scripts, styles, or resources can be loaded. This increases the risk of successful cross‑site scripting (XSS) attacks if any injection point exists.

**Evidence:**

"Header status: MISSING (severity: MEDIUM) \u2013 no CSP header present in response from https://fraudshield-xjgh.onrender.com"

**How to fix it:** Add a CSP header, e.g., `Content-Security-Policy: default-src 'self'; script-src 'self'` and tailor it to the application’s needs.
